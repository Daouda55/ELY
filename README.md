# ELY 

Bienvenue sur mon projet de marque ELY

## A propos 
ELY est une marque de vetementge qui souhaite proposer un univers elegant, moderne et distinctif, avec une attention particuliere portee a la qualite.

# Objectif du projet
Developper le site web officiel a la marque Ely, avec une presententation de la marque, un catalogue de produits et, progressivement, une boutique en ligne.

## Technologies utilisees
- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- Mysql

## Fonctionalites prevues 
- Page d'accueil
- Presentation de la marque 
- Catalogue de vetements
- Fiches produits 
- Paniers d'achat
- Espace client
